This website is a guide for travel experiences in Jamaica. It has a home page, an explore page where users can browse excursions, and a booking page where they can sign up for tours.

Technologies Used

• HTML5: Used to build the main structure and layout for all three files (index.html, explore.html, and booking.html).
• Custom CSS3: Used to set up the website's theme colors, clean up typography fonts, and align the page sections.
• JavaScript: Used to store the excursion details in an array of objects, loop through that data to generate the content cards automatically, and check that the booking form inputs aren't left empty.

Core Features

1. Multi-Page Navbar: A shared header menu that lets users navigate smoothly back and forth between all three pages.
2. Dynamic Card Generator: The explore page takes data from a JavaScript array and builds cards for each adventure with real titles, text, and picture links.
3. Form Validation: The booking form uses JavaScript to stop the page from hard reloading, checks that all fields are filled out, and pops open a success banner message.

Development History & Troubleshooting

My repository timeline has a lot of commits because I had a major setback during this assignment:
• Starting Out (Local Laptop): I began the assignment on my personal laptop using VS Code and GitHub Desktop. I set up my basic page layouts, linked my custom style sheets, and made my first few commits to track my early progress.
• The Laptop Crash (The Down): In the middle of working, my personal laptop stopped working completely. Thankfully, because I had been committing and pushing my code to GitHub regularly, all my files were backed up safely in the cloud.
• Moving to a Web Editor (The Up): I moved over to a backup computer to finish the work. Since I was working directly through the web browser, I logged into GitHub and used the online version of VS Code (vscode.dev) to pull my project back up.
• Final Polish & Edits: Working in the browser editor, I ran into layout issues where text wasn't centered, navigation menus looked squeezed, and button filtering was buggy. I systematically edited and refactored the files over several commits to fix the alignment, add real images, add Martha Brae to the booking dropdown, and clean up code comments until everything rendered perfectly.
